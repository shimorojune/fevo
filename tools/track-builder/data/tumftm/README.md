# TUMFTM source data

CSV files from [TUMFTM/racetrack-database](https://github.com/TUMFTM/racetrack-database), licensed LGPL-3.0, © Chair of Automotive Technology, Technical University of Munich. Unmodified; fetched with `pnpm --filter @fevo/track-builder fetch-tumftm`.

Format: `x_m, y_m, w_tr_right_m, w_tr_left_m`, centreline in metres with distances to each track edge.
